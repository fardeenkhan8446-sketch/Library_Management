\# Library Management System



\## Project Description

A Java-based Library Management System using Swing.



\## Features

\- Admin login and user registration

\- Add and view books

\- Search for books

\- Issue books to members

\- Return books

\- Save library data in text files



\## Technology Used

\- Java

\- Java Swing

\- File Handling
